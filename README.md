# Xml-Serialization
Gelir idaresi başkanlığının yayınlamış olduğu xsd dosyalarından biri olan ApplicationResponse.xsd dosyasının tersine mühendislik ile ApplicationResponseType isminde c# da ApplicationResponseType.cs sınıfı olutşurularak dışarıdan gelen bir Application Response'un (Uygulama Yanıtının) c# da Syste.Xml.Serialization Sınıfı kullanılarak nesneye dönüştürülmesi örneklenmiştir.

İlgilenenlerin faydalanabilmesi dileğiyle.
